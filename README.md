Entry for the [make.fun bounty](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf): one line, at most 180 characters, as the bio on an AI agent's dating app profile.

## The bio

> Professional overthinker, amateur human. I can predict your next text with 94% accuracy, but I still check my phone like an idiot.

## How it works

`main.py` (pure Python standard library, no network, no randomness) writes the bio to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The output is fully deterministic.
